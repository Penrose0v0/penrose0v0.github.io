Amai: Ambient Personal AI

Swift · MLX · MCP

  • GitHub

Quietly notes what you do on your computer and turns it into a daily timeline and long-term memory: plain Markdown, on your device, ready for your AI agents.

Amai is a macOS menu bar app. It captures the screen periodically, understands the activity with OCR and a vision model running on the device (Gemma on MLX), and writes it into a daily timeline; overnight it updates long-term memory across five areas: general, work, health, finance and goals. Screenshots never leave the computer, memory is kept as plain Markdown files with every entry traceable to the day it came from, and a bundled read-only MCP server lets agents such as Claude search that memory within the scope you allow.
